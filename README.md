# Отпуск 2027 · ПСО

Мобильное приложение для восьми врачей: Клепиков Е.Ю. (ЕЮ), Кардашина К.К., Лекерова Д.С., Хаматнурова А.А., Леонард Т.В., Алекешова Г.Ж., Давыдова Н.В., Омутов М.Ю.. Инициалы уточнены ЕЮ. Фамилии взяты из полного ноябрьского графика ПСО за 2026 год. Телефонные номера не переносятся и не хранятся.

Приложение: https://evgk724.github.io/pso-leave-2027/

## Как пользоваться

1. ЕЮ передаёт каждому врачу его персональную ссылку из раздела «ЕЮ». Ссылка предоставляет доступ к соответствующему профилю, поэтому пересылать её другим людям не следует.
2. Врач открывает ссылку, добавляет приложение на экран телефона, указывает остаток с 2026 года (включая 0).
3. Добавляет периоды, распределяет 42 дня за 2027 год и указанный остаток. При недопустимом пересечении приложение предлагает ближайшие варианты раньше и позже с учётом правил.
4. Нажимает «Передать пожелания ЕЮ». ЕЮ видит сообщение и число оставшихся. Положительный остаток с 2026 года подтверждает ЕЮ.
5. Когда все восемь врачей завершили пожелания и остатки подтверждены, итог создаётся автоматически. ЕЮ скачивает HTML для печати, CSV для Excel или выбирает «Печать / PDF». Для изменения готового графика ЕЮ возвращает конкретную заявку к редактированию, после чего итог формируется заново.

## Правила

- 42 дня отпуска за 2027 год, перенос с 2026 года учитывается отдельно.
- В одной части от 1 до 14 **дней отпуска**. Соседние части можно присоединять без разрыва, но суммарно не более 21 дня отпуска подряд: например, 14 + 7. Лимит действует и при присоединении остатка с 2026 года. Для следующего периода после 21 дня нужен хотя бы один календарный день разрыва. Праздничные дни не списываются, поэтому фактическое отсутствие иногда длиннее. Хотя бы одна часть за 2027 год должна быть 14 дней.
- С 1 мая по 30 сентября включительно — максимум 21 **день отпуска суммарно за все пять месяцев**, включая отпуск за 2027 год и перенос с 2026 года. Учитываются только дни внутри этих границ; федеральные праздники не расходуют лимит. Давыдова освобождена от сезонного лимита; общий предел 21 дня подряд действует для всех. В своём профиле врач видит использование и остаток сезонного лимита. Если ранее уже внесено больше 21 дня, даты сохраняются и могут переноситься постепенно с уменьшением превышения; передача пожеланий и формирование итога доступны после исправления.
- С Давыдовой любой врач может полностью пересекаться отпусками за 2027 год и перенесёнными с 2026, в любом сочетании. В каждый день вместе с ней в отпуске может быть только один коллега.
- Хаматнуровой разрешено полное пересечение с Алекешовой, независимо от года отпуска. Это разрешение действует в обе стороны.
- С Леонард любой врач может **полностью пересекаться** отпусками за 2027 год и перенесёнными с 2026, в любом сочетании и без ограничения длительности пересечения. В каждый день вместе с ней в отпуске может быть только один коллега.
- Для остальных пар сохраняется правило: остаток с 2026 года может пересекаться с отпуском другого врача за 2027 год суммарно до 3 **календарных дней на непрерывный период остатка**. Соседние части за 2026 год объединяются для этого лимита; совпадения с несколькими коллегами по этому правилу суммируются. Праздники и выходные входят в эти 3 дня. Два отпуска за 2027 год или два остатка за 2026 год у этих пар пересекаться не могут.
- Одновременно в отпуске могут быть максимум два врача. Третий врач на любую общую дату не допускается, в том числе в праздничный день и при полных пересечениях. Части отпуска одного врача не могут пересекаться. Все правила действуют одинаково при любом порядке внесения и редактирования дат. Под календарём выбранного месяца красным перечислены фактические пересечения: общие даты, число календарных дней, фамилии с инициалами и год списания каждого врача. Диапазоны обрезаются границами выбранного месяца.
- Периоды целиком находятся в 2027 году. 14 федеральных праздничных дат исключаются. Обычные и перенесённые выходные включаются.
- В 2027 году 351 день, который может засчитываться в отпуск. 8 × 42 = 336. Без пересечений остаётся 15 дней для переноса. Если остатков больше, приложение показывает минимальное необходимое число дней допустимых пересечений. Это оценка потребности, а не гарантия размещения: сохранение дат и формирование итога проверяются по фактическому расписанию. Суммарный перенос больше 15 дней сам по себе больше не блокирует отправку пожеланий и итог.
- Переносы выходных: 02.01 → 05.11; 03.01 → 31.12; 20.02 → 22.02. Дополнительные выходные: 03.05, 10.05, 14.06. Для сменной работы выходные показываются как ориентир; дежурства приложение не рассчитывает.

Источники: [Постановление Правительства РФ 17.09.2026 № 1187](https://www.consultant.ru/document/cons_doc_LAW_544706/), [ст. 120 ТК РФ](https://www.consultant.ru/document/cons_doc_LAW_34683/1ea2cd88521106bc484f44be9e24fa81034d13e5/). Последняя проверка: 13.10.2026.

## Установка и уведомления

**iPhone:** открыть персональную ссылку в Safari → «Поделиться» → «На экран Домой». Запустить по иконке → «Помощь» → «Включить уведомления». Разрешение выдаётся каждым владельцем телефона. [Web Push для приложений на экране Домой](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).

**Android:** Chrome → ⋮ → «Установить приложение». Уведомления включаются той же кнопкой.

Сервер напоминает незавершившим врачам один раз в три календарных дня, до 31.10.2026 включительно, в 09:00 по Екатеринбургу. После завершения заявки новые напоминания не создаются. Текст: «Пожалуйста, когда будет удобно, внесите пожелания по отпуску на 2027 год до 1 ноября. Спасибо! ЕЮ». Сообщения сохраняются в приложении; push поступают на телефоны с активной подпиской и разрешёнными уведомлениями. Доставку может задержать сеть или режим фокусирования телефона.

**Календарь:** файл .ics — разовая копия; подписка из «Помощь → Подключить календарь» автоматически обновляется с частотой, определяемой календарём. Ссылка календаря даёт доступ только к датам своего врача и не позволяет менять график. В события включены напоминания за 14 дней и за 1 день. Поддержка сигналов подписного календаря зависит от выбранного календарного приложения.

**Apple «Напоминания»:** прямого веб-доступа к этому приложению нет. Можно поделиться текстом задачи через системное меню телефона или импортировать VTODO в поддерживающую задачи программу. Это не двусторонняя синхронизация Apple «Напоминаний».

## Устройство проекта

GitHub Pages публикует только `docs/`. Данные, персональные ссылки, push-подписки и закрытый ключ VAPID хранятся в Supabase в отдельных таблицах `leave2027_*`; они недоступны `anon` и `authenticated`. Row Level Security включён. Доступ к ним имеет только серверная функция с служебной ролью. У неё собственная проверка случайных 256-битных персональных ссылок; проверка JWT шлюза выключена по этой причине.

Сохранение использует транзакционную проверку версии (`leave2027_commit`). При одновременной записи одной версии принимается только первая, вторая получает 409 и обновляет данные. Проверка правил выполняется сервером по той же логике, что используется интерфейсом. Состояние и сообщения для доставки сохраняются атомарно. Раздел ЕЮ защищён серверной проверкой, а не только скрытием кнопок.

`shared/engine.js` — единая логика. `scripts/build.mjs` копирует её в браузер и Edge Function. `supabase/setup.sql` содержит исходную схему. `supabase/functions/leave-api/index.ts` — сервер. Доступ к серверной функции: `docs/config.js`. В этом файле допустим только публичный адрес; персональные ссылки и закрытые ключи в репозиторий не помещаются.

Для автономной проверки до подключения сервера предусмотрен явно подписанный локальный черновик. Он не синхронизируется и не отправляет сообщения другим людям. При отсутствии сети в общем режиме запись не подтверждается как успешная.

## Проверка и публикация

```sh
node --test tests/*.test.mjs
node scripts/build.mjs
```

GitHub Actions выполняет проверки и публикует `docs/` на Pages. После изменения оболочки требуется обновить имя кэша в `docs/sw.js`. Исходный файл Excel, телефоны, реальные пожелания и персональные ссылки в репозиторий не включаются.

Печатная форма предусматривает подписи и утверждение работодателем. Автоматическое формирование файла не является кадровым утверждением графика.

Размер основного текста увеличен до 18 px при стандартных настройках. Интерфейс использует системное семейство шрифтов, относительные размеры и iOS Dynamic Type; увеличенный текст переносится без обрезания кнопок и фамилий.
